# The issues and PRs used as eval cases. See README.md.
#
# How they were chosen:
#
# - 11 cases are items from October 2026 that a maintainer gave
#   written feedback on, after reading the bot's cards for them.
# - 50 cases are past items, 25 PRs and 25 issues, opened between
#   2026-02-15 and 2026-08-15. Each got a substantive answer from a
#   maintainer, who was not the author, within 7 days.
# - The past items were sorted into kinds by fixed rules on what
#   happened to them. For PRs, the kinds are merged, closed as a
#   duplicate, not help wanted, untested AI work, and opened by a
#   maintainer. For issues, they are duplicate, likely written by an
#   LLM, user bug report, feature request, and opened by a
#   maintainer.
# - 5 cases of each kind were picked in a seeded random order, with
#   no model involved. Kinds with fewer than 5 items were filled from
#   the extra items of the other kinds of the same type.
# - Items by the maintainers listed in ../gather.py were then left
#   out, because the bot writes their card without the model. This
#   left 9 items with feedback, 23 past PRs, and 22 past issues.
#
# The kinds are not listed here, so that a model reading this file
# can't learn the answers from it.
#
