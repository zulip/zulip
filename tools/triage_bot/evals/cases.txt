# How they were picked:
#
# - 11 items are from October 2026. A maintainer gave feedback on
#   the bot's cards for them.
# - 50 items are older: 25 PRs and 25 issues from 2026-02-15 to
#   2026-08-15. A maintainer other than the author answered each one
#   within 7 days.
# - The older items were grouped by what happened to them.
# - PR groups: merged, closed as a duplicate, not help wanted,
#   untested AI work, opened by a maintainer.
# - Issue groups: duplicate, likely written by an LLM, user bug
#   report, feature request, opened by a maintainer.
# - 5 items were picked from each group in a fixed random order.
#   Small groups were topped up from other groups of the same type.
# - Items by maintainers listed in ../gather.py were dropped. That
#   left 9 items with feedback, 23 older PRs and 22 older issues.
#
# The file doesn't say which group each item is in, so a model
# reading it can't learn the answers.
