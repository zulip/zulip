**Feature level ZF-546a5d**

* [All REST API endpoints](/api/http-headers#rate-limiting-response-headers):
  The `retry-after` value in rate limit error responses, and the
  `Retry-After` HTTP header, are now always a whole number of seconds,
  rounded up. Previously, both were an unrounded number of seconds, which
  could describe a wait shorter than the client's round trip to the
  server, and which the `Retry-After` header's format does not permit.
