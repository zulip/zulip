* [`POST /messages`](/api/send-message): Added support for the
  [`Idempotency-Key`](/api/http-headers#the-idempotency-key-request-header)
  request header, which lets clients safely retry sending a message
  without it being sent twice. The server uses the
  `INVALID_IDEMPOTENCY_KEY` error code when the header is not a UUID
  in a supported format, and the `IDEMPOTENCY_KEY_IN_USE` error code,
  with a 409 status, when a request with the same key is still being
  processed.
