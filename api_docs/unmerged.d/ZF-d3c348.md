* The resolved-topic prefix (`✔ `) no longer counts toward
  [`max_topic_length`](/api/register-queue). Resolving a topic of up
  to that length preserves the original name, and a stored resolved
  topic may exceed `max_topic_length` by the length of the prefix.
  [`PATCH /messages/{message_id}`](/api/update-message) and the topic
  visibility endpoints follow the same rule.
