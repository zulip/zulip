* [`POST /users/me/subscriptions`](/api/subscribe),
  [`POST /channels/create`](/api/create-channel): Requests that collide
  with an existing channel the acting user cannot access now return an
  HTTP 403 `PERMISSION_DENIED` error without exposing the channel's name
  or details. Previously, `POST /users/me/subscriptions` returned HTTP
  400 `BAD_REQUEST` naming the channel and `POST /channels/create`
  returned HTTP 409 `CHANNEL_ALREADY_EXISTS`.
