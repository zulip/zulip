* [`PATCH /streams/{stream_id}`](/api/update-stream): Added the `default_color` parameter, allowing organization administrators to set or clear a channel's default color.
* [`GET /streams`](/api/get-streams), [`GET /subscriptions`](/api/get-subscriptions), and [`GET /events`](/api/get-events): Channel objects now include `default_color`. Subscription objects now include the effective `color`, `color_is_default`, and `auto_color` fields.
* [`PATCH /users/me/subscriptions/{stream_id}`](/api/update-subscription-property): Passing `null` for the `color` property resets the user's color to the channel default.
