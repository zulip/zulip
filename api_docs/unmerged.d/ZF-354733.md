* The undocumented `PATCH /users/me/subscriptions` endpoint for
  bulk-updating channel subscriptions has been deprecated and removed.
  It was a duplicate of the bulk-subscribe and bulk-unsubscribe
  endpoints, and we do not expect that any clients are currently using
  it. Clients should use the
  [`POST /users/me/subscriptions`](/api/subscribe) and
  [`DELETE /users/me/subscriptions`](/api/unsubscribe) endpoints
  instead.
