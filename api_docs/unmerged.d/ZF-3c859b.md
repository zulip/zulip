* `POST /bots`: Sending `payload_url` for a bot that is not an
  outgoing-webhook bot now returns an HTTP 400 error. Previously,
  `payload_url` was silently ignored for generic and incoming-webhook
  bots, and silently stored (but unused) on the `Service` row for
  embedded bots.
* `POST /bots`: The `config_data` parameter is now only accepted for
  incoming-webhook and embedded bots; sending it for other bot types
  returns an HTTP 400 error. Previously, it was silently ignored.
* `POST /bots`: Sending `service_name` for a generic bot now returns
  an HTTP 400 error. Previously, `service_name` was silently ignored
  for generic bots.
* `POST /bots`: Creating an outgoing-webhook bot without a
  `payload_url` now returns an HTTP 400 error. Previously, the server
  silently created a bot with an empty service URL, leaving the
  webhook with nowhere to post to.
