* [`PATCH /messages/{message_id}/link_previews`](/api/update-link-previews):
  Added new endpoint to remove individual [link
  previews](/help/allow-image-link-previews) from a message, for users with
  permission to edit the message's content. A removed preview is not
  displayed for any user. Clients receive the re-rendered message as an
  [`update_message`](/api/get-events#update_message) event with
  `rendering_only: true`.
