**Feature level ZF-334371**

* `PATCH /bots/{bot_id}`: The `config_data` parameter is now only
  accepted for incoming-webhook and embedded bots; sending it for
  another bot type returns an HTTP 400 error. Previously, the server
  had a bug where config entries were written into `BotConfigData`
  for any bot type, even though other bot types have no meaningful
  use for them. Additionally, `config_data` submitted on update is
  now validated against the integration or embedded-bot handler's
  schema (merged with the bot's existing config, so partial updates
  still work); previously the update path accepted arbitrary keys
  and values without validation.
