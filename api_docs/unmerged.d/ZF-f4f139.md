  * `PATCH /bots/{bot_id}`: The `config_data` parameter is now also
    accepted for incoming-webhook bots. The value is validated against
    the integration's configuration schema and merged with the bot's
    existing config, matching the behavior for embedded bots. When the
    request supplies an `integration_id` that differs from the bot's
    current integration, the bot's existing config is cleared instead
    of merged to avoid stale config_data under the new schema.
    Previously, sending `config_data` for an incoming-webhook bot
    returned an HTTP 400 error.
