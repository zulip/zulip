* `PATCH /realm`, [`POST /register`](/api/register-queue),
  [`GET /events`](/api/get-events): Added `can_bots_invite_users_group`
  realm setting, which is a [group-setting
  value](/api/group-setting-values) describing which bots are allowed
  to call the invitation endpoints. The default value is the Nobody
  group, preserving previous behavior that bots cannot access these
  endpoints.
* [`POST /invites`](/api/send-invites), [`GET /invites`](/api/get-invites),
  [`DELETE /invites/{invite_id}`](/api/revoke-email-invite),
  [`POST /invites/{invite_id}/resend`](/api/resend-email-invite),
  [`POST /invites/multiuse`](/api/create-invite-link),
  [`DELETE /invites/multiuse/{invite_id}`](/api/revoke-invite-link):
  Bots that belong to `can_bots_invite_users_group` may now use these
  endpoints, subject to the same invitation permissions that apply to
  human users.
