* `PATCH /bots/{bot_id}`: The `service_interface` and
  `service_payload_url` parameters can each be sent independently
  to update an outgoing-webhook bot. Sending only `service_payload_url`
  now preserves the bot's existing `service_interface`.

* `PATCH /bots/{bot_id}`: `service_interface` sent without
  `service_payload_url` is no longer silently discarded; the server
  now applies it (on outgoing-webhook bots) or returns an HTTP 400
  error (on other bot types, or when the value is invalid).
