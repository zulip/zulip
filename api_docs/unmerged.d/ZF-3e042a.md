**Feature level ZF-3e042a**

* `PATCH /bots/{bot_id}`: The `service_interface` and `service_payload_url`
  parameters are now applied independently for outgoing-webhook bots.
  Previously, the server had a bug where `service_interface` was silently
  ignored unless `service_payload_url` was also sent, and sending
  `service_payload_url` alone silently reset the interface to Generic.
  The endpoint also now returns an HTTP 400 error when either parameter
  is sent for a bot that is not an outgoing-webhook bot; previously the
  request silently no-oped.
