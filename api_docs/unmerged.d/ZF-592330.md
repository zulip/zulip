* [`POST /register`](/api/register-queue): Added the
  `realm_upload_quota_used_bytes` field to the response, containing the
  total number of bytes currently used for uploaded files in the
  organization, if it has an upload quota.
* [`GET /events`](/api/get-events): The `realm` op `update_dict` event
  for the `default` property can now contain an `upload_quota_used_bytes`
  field, sent to everyone in an organization with an upload quota when a
  file is uploaded or deleted.
