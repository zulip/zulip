**Feature level ZF-47b798**

* `POST /mcp`: New endpoint implementing the Model Context Protocol
  (JSON-RPC 2.0 over HTTP), so that AI agents can access Zulip, acting
  as the user whose API key they authenticate with. Includes the
  read-only tools `get_messages` (accepting the standard
  [narrow](/api/construct-narrow) filter language, including full-text
  search, and the same anchor-based range parameters as
  [`GET /messages`](/api/get-messages)), `list_channels`, `list_topics`,
  `list_linkifiers`, and `get_users`. Access requires the organization
  to have enabled the `enable_mcp_access` realm setting. The endpoint is
  experimental, and its tools may change without notice.
