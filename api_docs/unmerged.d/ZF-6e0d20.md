* [`POST /register`](/api/register-queue): Added the
  `defer_long_term_idle_reactivation` parameter, which lets the server
  respond to a long-term-idle user before their account is ready. Such
  a response has the new `long_term_idle` and `long_term_idle_days`
  fields.
* [`GET /events`](/api/get-events): Added the `long_term_idle` event,
  sent once a long-term-idle user's account is ready.
