* [`GET /calls/jitsi_jwt/create`](/api/create-jwt-jitsi-video-call): Added a new
  endpoint to generate a Jitsi Meet video call URL with JSON Web Token
  (JWT) authentication.

* [`POST /register`](/api/register-queue): Added
  `server_jitsi_jwt_configured` boolean field to the response,
  indicating whether the Zulip server has JSON Web Token credentials set
  for its configured Jitsi Meet server.

* [`POST /register`](/api/register-queue): When `server_jitsi_jwt_configured`
  is `true` and `realm_jitsi_server_url` is `null`, clients must now call
  [`GET /calls/jitsi_jwt/create`](/api/create-jwt-jitsi-video-call) to obtain a call
  URL. Previously, clients constructed a Jitsi Meet call URL from
  `realm_jitsi_server_url` and `server_jitsi_server_url` directly; see
  feature level 212.
