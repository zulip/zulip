* `PATCH /realm`, [`POST /register`](/api/register-queue),
  [`GET /events`](/api/get-events): Added `can_change_name_group`, a group-based organization permission setting controlling who can change their own name. This setting supports system groups and custom user groups.

* `PATCH /realm`, [`POST /register`](/api/register-queue),
  [`GET /events`](/api/get-events): Replaced the `name_changes_disabled` boolean organization setting and the `realm_name_changes_disabled` initial state and event field with `can_change_name_group` and `realm_can_change_name_group`, respectively.
